# QMDB 脏 twig 去重、上层批量折叠与空树回滚修复

日期：2026-09-14，接续 [devlog-160](devlog-160-h2-trusted-qc-gate-20260914.md)。
**4 节点 1M 成功提交 TPS 仍未实测达标。** 本轮回到树更新性能，保持 H2 共识、
二叉树 QMDB 状态读取、叶/账户编码、正常执行校验和 WAL 同步。

## 审查依据与实际热点

重新阅读固定 n42-rs 提交 `255a2ec527113cc891baeabf0d9e63515881c5d1`：其上层树缓存
改善重复 root/proof 的整树折叠，但上游也明确记录 50M keys 块延迟没有改善，不能
把缓存或更少哈希自动等同于吞吐收益。本地 leaf tree 已有缓存，本轮不重复移植。

当前实现每次 set 的旧槽失活和新槽激活都向 `BTreeSet` 插入 twig ID，即使该 twig
已经被本块标脏。root 随后沿每个脏 twig 的路径分别重算，共享祖先重复计算。
大量账户更新时，标记动作远多于不同 twig 数。

新实现：

- `DirtyTwigs` 使用按 twig ID 索引的 membership bit 和 ID Vec。首次置脏才入队，
  后续同 twig 更新只检查同一 bit；无需每次查有序树。
- root 取出并排序去重后的 ID，逐层在原 Vec 中压缩父索引。每个共享祖先只计算
  一次，所有修改过的子节点就绪后才计算父哈希，未触及子树保留原缓存。
- 用完的 ID Vec 清空后归还供下次复用；回滚截断时同步清理 membership bit。
  membership words 按最高 twig 范围分配，Vec 容量可保留历史峰值，**不是 RSS 限额**。
- 格式、排序语义、删除/空值区别、undo 内容和正常状态的根不变。没有修改共识或
  以关闭同步、读取校验、重执行换取耗时下降。

## 对照暴露了原有空树缓存错误

新增与完整 `QmdbCompatTree` 对照的回归：

1. 从空树追加 7 个 twig，保存 undo 并计算根，上层容量为 8。
2. 撤销到空树，再读一次 root。
3. 追加 4 个 twig 加 1 个条目，上层容量仍为 8。

原实现虽然逐叶清空被撤销的 twig，但空树 root 直接清除 dirty 并返回 NULL，
未修复或失效化上层祖先。再次达到相同容量时，未被新条目触及的分支仍有旧祖先，
导致根与完整树不同。已在**本轮修改前的原始源码**上确认测试失败。

修复为空树 root 清空 upper 缓存并设置 `upper_cap=0`，下一次非空读取重建。
这是一项独立正确性修复：三种计时实现均带同样修复，避免把修错与优化收益混算。
原始未修源码和失败日志保留。没有声称实际链曾遇到该路径，也不会自动改写已有
错误根的持久化历史；原有根校验仍会拒绝不一致记录。

## release 三组对照

使用 gov5 account key/value 编码的合成账户：初始 200k 或 2M 个账户，每块更新
同一组 147,000 个不同账户。输入按账户编号生成、key 非有序，每种实现都在计时内
执行相同的原地排序、借用操作应用、值复制、undo 记录与根计算。

每种状态规模 6 组轮换三种执行顺序，每进程 3 块；每格 18 个样本。

| 初始账户 | 原标记/逐路径 | 仅共享祖先折叠 | 位标记 + 缓冲复用 + 共享折叠 | 组合方案变化 |
| --- | ---: | ---: | ---: | ---: |
| 200k | 70.6625 ms | 73.2930 ms | 66.6385 ms | -5.70% |
| 2M | 83.4320 ms | 82.6985 ms | 79.0575 ms | -5.24% |

单独祖先折叠为 +3.72% / -0.88%，不是稳定收益；不能把理论哈希次数下降直接
当作等比例提速。组合方案在两种状态规模下均改善，和去掉重复有序树查找/复用
工作缓冲相符，但未用硬件计数器分离各项成本。没有 CPU 绑定或独占宿主机；
全部原始样本、极值和轮换次序均保留。计时开始前本轮编译、测试、clippy 已完成。

108 个计时样本的对应状态根和完整 undo 摘要全部相同，每块还在计时外核对撤销根、
append cursor、重新应用根和所有更新值。独立分配计数仅少 22–173 次请求、
1,248–3,960 个累计申请字节/块，**没有大的分配量下降，也不据此声称 RSS 下降**。
分配计数进程的耗时未混入计时结果。

测量不含初始树/输入生成、撤销验证、read view、WAL、EVM、网络或 H2。
它证明这组负载的树更新阶段改善，不能换算为整链 1M TPS。
